# Muguetli

وب‌سایت دوزبانهٔ Muguetli با Next.js و React.

## اجرای production روی سرور

پیش‌نیازها: Node.js نسخهٔ `22.13` یا بالاتر و pnpm.

```bash
pnpm install --frozen-lockfile
pnpm build
PORT=3000 pnpm start
```

سرور روی `0.0.0.0` گوش می‌دهد و مقدار `PORT` را از محیط می‌خواند. برای استفاده با دامنه، برنامه را پشت reverse proxy مانند Nginx اجرا کنید و TLS را روی proxy فعال کنید. در سرویس‌هایی مانند systemd یا Docker، همین دستور build و start را اجرا و `PORT` را در تنظیمات محیطی سرویس تعیین کنید.

نشانی سایت، شمارهٔ رسمی واتس‌اپ و ایمیل رسمی پرسش‌های خصوصی در `.env.example` آمده‌اند. تا زمانی که شماره و ایمیل تأییدشده تنظیم نشوند، رابط کاربری وضعیت «متصل نشده» را صادقانه نشان می‌دهد و هیچ مقصد ساختگی نمایش نمی‌دهد؛ فایل `.env` را commit نکنید.

فهرست اولیهٔ مجموعه‌ها و یادداشت‌های ژورنال در `lib/editorial.ts` نگهداری می‌شود. نام‌ها، روایت‌های نهایی و جزئیات فنی آثار فقط پس از تأیید رسمی اضافه شوند.

## اجرای محلی

```bash
pnpm install --frozen-lockfile
pnpm dev
```
